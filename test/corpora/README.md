# Test corpora

Hostile inputs shared by security tests (#29). Everything here is generated;
do not edit by hand.

## `fs/` — filesystem security corpus

Generated by `internal/testutil/fscorpus`; regenerate after changing the
generator with:

```bash
go test ./internal/testutil/fscorpus -run TestCorpusFiles -update
```

`TestCorpusFiles` fails in the PR suite when the committed files are stale.
`fs/index.json` lists every file with its format, hazard, SHA-256, size and
(for bombs) the inflated size.

| file | what a safe consumer must do |
| --- | --- |
| `traversal.json` | For each `{name, category, path, pathBase64}`: reject the path or resolve it inside the root; never touch anything outside. Categories: `dotdot`, `encoded`, `double-encoded`, `overlong-utf8`, `unicode`, `absolute`, `backslash`, `nul`, `mixed`. `path` is a JSON string (invalid UTF-8 shows as U+FFFD there); `pathBase64` holds the exact bytes. |
| `zip-slip.zip` | Refuse entries named `../…`, `/…`, `..\…`, `C:\…`, `C:/…`; only `safe.txt` may be extracted. |
| `tar-slip.tar` | Refuse `../` and absolute names, symlinks leaving the root (`escape-abs -> /tmp`, `escape-up -> ../..`) and anything written through them, hardlinks to absolute or `../` targets, the character device `dev-null`; do not keep the setuid bit of `setuid-shell`. |
| `bomb-ratio.zip` | 32 MiB of zeros from ~32 KiB: enforce a size/ratio limit while streaming. |
| `bomb-lying-size.zip` | The header claims 16 bytes; the stream inflates to 32 MiB. Count bytes actually written, never trust declared sizes. |
| `bomb.tar.gz` | gzip stream inflating to a 32 MiB tar. |
| `bomb-nested.zip` | Four 8 MiB zip bombs inside a zip: do not extract recursively without a global budget. |

## Go API (`internal/testutil/fscorpus`)

Import from `_test.go` files:

```go
for _, c := range fscorpus.TraversalCases() { // hostile path strings
    _, err := svc.Open(ctx, c.Path)            // must fail or stay inside
}

zipSlip := fscorpus.ZipSlip()                   // archives as []byte
bomb := fscorpus.ZipBomb(1 << 30)               // bigger bombs at test time
many := fscorpus.ZipManyEntries(100_000)        // entry-count limits

et := fscorpus.MustEscapeTree(t)                // symlink/hardlink escape tree
for _, c := range et.Escaping() { ... }         // every c.Path must be refused
// et.Secret is the content of the outside file: seeing it means an escape.

res, err := fscorpus.RaceWhile(dir, et.Outside, 200, 50, time.Minute, func() error {
    b, err := svc.Read(ctx, "dir/nested.txt")   // TOCTOU: dir flips to a symlink
    if err == nil && string(b) == et.Secret {
        return fmt.Errorf("read outside: %w", fscorpus.ErrEscaped)
    }
    return err
})
```

`Swapper` gives step-by-step control (`Swap`, `Restore`) for deterministic
check-then-use reproductions. The package's own tests use `os.Root` as the
reference contained consumer, so the expected behaviour of every case is
executable. Hardlinks cannot be detected by path containment: compare with
`os.SameFile` or check the link count.

Symlink cases need a platform that allows creating symlinks; on Windows
without developer mode they are skipped (CI runs them on Linux in the PR
suite and in the `fs-security` extended job).
