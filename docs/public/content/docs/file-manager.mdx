---
title: File Manager
description: Browse, upload, edit and download files of stacks and volumes in the browser.
---

The File Manager opens on a stack's **Files** tab (the stack's folder) and
on a volume's **Files** tab (the data inside the volume). You never need to
copy files to a server by hand.

## Browse and organize

- The buttons at the left of the toolbar are **Upload Files**, **Upload
  Folder**, **New File** and **New Folder**; point at one to see its name.
  You can also drag files onto the page.
- An item's menu has **Download** (**Download as ZIP** for a folder),
  **Copy**, **Cut**, **Paste Into Folder**, **Rename**, **Permissions**
  and **Delete**.
- **Create Archive** packs files into a `.zip` or `.tar.gz`. **Extract**
  unpacks a `.zip`, `.tar.gz` or `.tgz`.

For a lot of data, upload one archive and extract it on the server.

Deleting can't be undone. Uploads stop if you reload or close the tab;
copying, extracting and the other file jobs keep running on the server.

## Edit a file

Click a file to open it in the editor. It highlights the syntax, has
**Search and Replace**, and can **Format** YAML and JSON. Press **Save** or
<kbd>Ctrl</kbd> <kbd>S</kbd>.

- The language select starts at **Auto Detect**, which names the language
  it found from the file name, a shebang such as `#!/bin/bash` or the
  content. Pick a language there to override it.
- **Preview** shows a Markdown file the way GitHub does, with tables, task
  lists and alerts such as `> [!NOTE]`. Images show as links.
- If the file changed on the server while you edited it, you can
  **Compare**, **Reload From Disk**, **Save As** another file or
  **Overwrite**.
- In a stack, saving `compose.yaml` or `.env` does not deploy (see
  [Stacks](/stacks#edit-the-files)).
- Images are previewed; other binary files can be downloaded.

## Limits

| Limit | Default |
| --- | --- |
| Largest file you can edit (larger files open read-only) | 512 KB |
| Largest upload, per file | 2 GB |
| Largest download, or archive you create | 10 GB |

Your reverse proxy must allow uploads this large too. To change the limits,
see [Configuration](/configuration#file-manager). Docker Manager's own
volumes, and volumes with a driver other than `local`, have no **Files**
tab.

## Good to know

- In a stack, the Compose files and env files the stack uses, wherever
  they are, need the **View Compose Definition** and **Edit Compose
  Definition** permissions. This also applies when you download, copy,
  move, delete or extract into a folder that holds one.
- Until a server's agent is upgraded, opening or changing any file of its
  stacks needs these permissions too.
- In a stack's folder, symbolic links are listed but never followed: open
  the file or folder they point to instead.
