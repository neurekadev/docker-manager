Docker Manager is a web app for the Docker servers you run yourself. You
open it in your browser to run your apps, keep them up to date and back
them up, whether you have one server or many.

## How it works

Docker Manager has two parts:

- The **manager** is the web app. You run it once.
- The **agent** is a small container on every server you want to manage. It
  connects to the manager and does the work on its server. It opens no
  ports, so the server needs no firewall changes.

Each server with its agent is called an **environment**. You can manage
many environments from one manager.

Longer tasks, such as deploying a stack or taking a backup, run as
**jobs**. You can follow their progress, and they keep running when you
close the browser.

## What you need

- A Linux server with a 64-bit Intel or AMD processor (amd64).
- Docker Engine 25.0 or newer with the Compose plugin.
- A domain name, such as `docker.example.com`, and a reverse proxy that
  serves it over HTTPS. Docker Manager does not work over plain HTTP.
- Access to the Docker Manager images. The image registry is private for
  now; you need an account on `code.neureka.dev`.

Docker Desktop, rootless Docker, the Docker built into NAS systems and
Docker Swarm are not supported.

<Callout type="warn" title="Protect your sign-in">
  The agent has full control of Docker, and so of the whole server. Anyone
  who can sign in to Docker Manager with enough permissions can do the same.
  Use a strong password and turn on two-factor sign-in (see
  [Sign-in and security](/docs/sign-in-and-security)).
</Callout>
