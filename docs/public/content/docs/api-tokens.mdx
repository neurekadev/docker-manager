---
title: API tokens
description: Let scripts use Docker Manager with only the permissions you give them.
---

An **API token** lets a script or another tool use the Docker Manager API
as you, with only the actions you grant it. A token can never do more than
you can do yourself.

## Create a token

1. Click the round button with your initial at the top right, choose
   **API tokens** and press **Create token**.
2. Enter a **Name**, for example `Backup script`.
3. Choose when it **Expires**: in 7, 30 or 90 days, or on a date.
4. Under **What the token may do**, allow only what the script needs. You
   can start from a preset.
5. Press **Create token** and confirm it's you.

The token is shown **once**. Copy it and store it safely. Scripts send it
as `Authorization: Bearer <token>`.

## Manage tokens

The **API tokens** page (**Profile → API tokens**) lists your tokens with
their status, expiry and when they were last used.

- **Rename** changes a token's name.
- **Revoke** stops a token at once. This is final.

The owner sees every user's tokens under **Settings → API tokens**, and
can revoke them there. Nobody can see a token's value again.

## Good to know

- Tokens can't manage people, permissions or other tokens. Those need a
  signed-in browser.
- The owner decides in the [sign-in policy](/docs/sign-in-and-security#the-sign-in-policy)
  whether tokens are allowed and how long they may live.
- Disabling a person's account revokes their tokens for good.
