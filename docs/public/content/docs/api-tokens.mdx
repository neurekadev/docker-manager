---
title: API Tokens
description: Let scripts use Docker Manager with only the permissions you give them.
---

An **API token** lets a script or another tool use Docker Manager as you,
with only the actions you grant it. A token can never do more than you can.

## Create a token

1. Click the round button with your initial at the top right, choose
   **API Tokens** and press **Create Token**.
2. Enter a **Name**, for example `Backup script`, and when it **Expires**.
3. Under **What the Token May Do**, allow only what the script needs.
4. Press **Create Token** and confirm it's you.

The token is shown **once**. Copy it and store it safely. Scripts send it
as `Authorization: Bearer <token>`.

## Manage tokens

The **API Tokens** page lists your tokens with their expiry and when they
were last used. **Revoke** stops a token at once.

The owner sees everyone's tokens under **Settings → API Tokens** and can
revoke them there.

Good to know:

- Everyone except the owner needs the **Create API Tokens** permission.
- Tokens can't manage people, permissions or other tokens.
- The owner decides in the [sign-in policy](/users-and-groups#sign-in-policy)
  whether tokens are allowed and how long they may live (90 days by
  default).
- Disabling a person's account revokes their tokens.
