---
title: Quickstart
description: Install Docker Manager, create your account and connect your first server.
---

This guide installs the manager and an agent on one server. It takes about
ten minutes.

## 1. Log in to the image registry

The images are private for now. On `code.neureka.dev`, create an access
token with the `read:package` permission, then log in on your server:

```bash
docker login code.neureka.dev
```

Enter your username, and paste the token as the password.

## 2. Create the files

Make a folder for Docker Manager and go into it:

```bash
mkdir -p /opt/docker-manager && cd /opt/docker-manager
```

Create a file named `compose.yaml` with this content:

```yaml title="compose.yaml"
name: docker-manager

services:
  docker-manager:
    image: code.neureka.dev/docker-manager/docker-manager:edge
    restart: unless-stopped
    ports:
      - "8080:8080"
    environment:
      DOCKER_MANAGER_PUBLIC_URL: ${DOCKER_MANAGER_PUBLIC_URL}
      DOCKER_MANAGER_TRUSTED_PROXIES: ${DOCKER_MANAGER_TRUSTED_PROXIES}
    volumes:
      - data:/var/lib/docker-manager
    labels:
      docker-manager.role: manager
    networks:
      - docker-manager

  docker-agent:
    image: code.neureka.dev/docker-manager/docker-agent:edge
    restart: unless-stopped
    depends_on:
      - docker-manager
    environment:
      DOCKER_AGENT_MANAGER_URL: http://docker-manager:8080
      DOCKER_AGENT_MANAGER_ALLOW_HTTP: "true"
    volumes:
      - /var/run/docker.sock:/var/run/docker.sock
      - /var/lib/docker/volumes:/var/lib/docker/volumes
      - stacks:/var/lib/docker/volumes/docker-manager_stacks/_data
      - agent:/var/lib/docker-agent
    labels:
      docker-manager.role: agent
    networks:
      - docker-manager

networks:
  docker-manager:
    name: docker-manager

volumes:
  data:
  agent:
  stacks:
```

Then create a file named `.env` next to it:

```bash title=".env"
# The address you will open Docker Manager at. It must start with https://
DOCKER_MANAGER_PUBLIC_URL=https://docker.example.com

# The address of your reverse proxy. This value fits a proxy that runs on
# this server. If your proxy runs on another machine, put that machine's
# IP address here instead, for example 192.168.1.10.
DOCKER_MANAGER_TRUSTED_PROXIES=172.16.0.0/12
```

Replace `docker.example.com` with your own domain name.

<Callout title="Keep these lines as they are">
  The agent needs the Docker socket and Docker's volume folder
  (`/var/lib/docker/volumes`) at the same path inside its container. Keep
  the project name `docker-manager` too. If your Docker keeps its data
  somewhere else, see [Configuration](/docs/configuration#dockers-data-folder).
</Callout>

## 3. Start it

```bash
docker compose up -d
docker compose ps
```

After a minute, both containers show as running and `healthy`.

## 4. Put HTTPS in front of it

Docker Manager listens on port `8080` of your server, over plain HTTP. Point
your reverse proxy at it, so that your domain name opens Docker Manager over
HTTPS. If your proxy runs in Docker on this server, you can instead connect
it to the `docker-manager` network and point it at
`http://docker-manager:8080`.

Your proxy must:

- use a certificate your browser trusts,
- allow WebSocket connections,
- keep idle connections open for at least 60 seconds,
- allow uploads as large as the files you want to upload (1 GB is a good
  start),
- pass on the original host name and forwarded headers. Most proxies do
  this by default.

## 5. Create your account

Open your address, for example `https://docker.example.com`.

<Callout type="warn" title="Do this right away">
  The first person who opens a new Docker Manager becomes its owner, and
  the owner can do everything. Create your account as soon as Docker
  Manager is running.
</Callout>

Choose a username and a password of at least 15 characters, then press
**Create owner account**.

Then open **Settings → Profile and security** and add an authenticator app
or a passkey. See [Sign-in and security](/docs/sign-in-and-security).

## 6. Connect this server

1. Open **Environments** and press **Add environment**.
2. Give it a name if you like (without one, the server's name is used), and
   press **Create install command**.
3. Open the **On the Docker Manager host** tab and copy the command.
4. Run it on your server, in the folder with your `compose.yaml`
   (`/opt/docker-manager`).

The command hands a one-time code to the agent that is already running. The
page shows **Connected** within a few seconds. Your server now appears with
its containers, images, volumes and networks.
