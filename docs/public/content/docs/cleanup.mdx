---
title: Cleanup
description: Free disk space by removing unused containers, images, networks, volumes and build cache.
---

Docker keeps old images, stopped containers and build cache until you
remove them. Docker Manager can clean them up once, or on a schedule.

## Clean up once

The **Containers**, **Images**, **Volumes**, **Networks** and **Builds**
pages each have a **Prune** button (for example **Prune images**).

1. Press it and choose what to remove (**Change options**).
2. Press **Preview** to see exactly what would go, and how much space you
   get back.
3. Press **Remove … objects** to confirm.

Nothing is saved: the next time, you choose again.

## Maintenance policies

A **maintenance policy** cleans up on a schedule.

1. Open **Maintenance** and press **Create maintenance policy**.
2. Choose the **Environments**. Each server can have only one maintenance
   policy.
3. Turn on the rules you want:
   - **Stopped containers** (exited and dead ones by default; running and
     paused containers are never removed),
   - **Dangling images** (images without a tag) or **All unused images**,
   - **Unused networks**,
   - **Build cache**, with an optional amount to keep,
   - **Anonymous volumes** and **Named volumes**. These delete data, so you
     must tick **I understand that removing volumes deletes the data in
     them**.
4. For each rule you can remove only objects older than some days or
   hours, include or skip objects by label, and list objects to **Never
   remove**.
5. Turn on **Run automatically** and pick the schedule.

Every rule starts off, with an age limit of 30 days.

On a policy's page, **Preview** shows what a run would remove right now,
and **Run now** runs it. A removal can't be undone.

**Maintenance → Default rules** sets the rules new policies start with.
Existing policies keep their own.

## What is always kept

- Docker Manager's own containers, images, volumes and networks.
- Stacks Docker Manager manages, with their images.
- The images of containers Docker Manager created, so it can recreate them.
- Backup data.

Every object is checked again right before it is removed, so something
that came into use after the preview is kept.
