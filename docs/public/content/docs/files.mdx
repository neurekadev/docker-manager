title: Files
description: Browse, upload and edit files of stacks and volumes in the browser.
---

The file manager opens on a stack's **Files** tab (the stack's folder) and
on a volume's **Files** tab (the data inside the volume).

## Browse and organize

- **Upload** adds files, or a whole folder (**Upload folder**). You can also
  drag files onto the page.
- **New file** and **New folder** create empty ones.
- **Filter by name** narrows the list. Hidden files (names that start with
  a dot, like `.env`) are shown; **Hide hidden files** leaves them out.
  **Show permissions and owners** shows more.
- An item's menu offers **Download**, **Copy**, **Cut**, **Paste into
  folder**, **Rename**, **Permissions** and **Delete**. A folder downloads
  as a ZIP file.

Deleting can't be undone: Docker Manager keeps no copy.

Good to know:

- Uploads keep going while you open other pages of Docker Manager.
  Reloading or closing the browser tab cancels the uploads still running;
  your browser asks first.
- Copying, moving, deleting, archiving, extracting and permission changes
  keep running on the server. When you come back, they show under the files
  again, with **Cancel** while they run.

## Archives

- **Create archive** packs files into a `.zip` (opens anywhere) or a
  `.tar.gz` (keeps Linux permissions).
- **Extract** unpacks a `.zip`, `.tar.gz` or `.tgz` file, into a new folder
  or the current one. Files that would be overwritten are listed first.

Uploading a large amount of data? Upload it as one archive and extract it
on the server.

## Edit a file

Click a file to open it in the editor. It highlights the syntax, can
**Format** YAML and JSON, and has **Search and replace**. Press **Save** or
<kbd>Ctrl</kbd> <kbd>S</kbd>.

<kbd>Tab</kbd> indents the line (or the selected lines) and
<kbd>Shift</kbd> <kbd>Tab</kbd> moves them back out. To leave the editor
with the keyboard, press <kbd>Esc</kbd> and then <kbd>Tab</kbd>.

The arrow next to **Format** has two more choices:

- **Minify** puts a JSON file on one line without spaces. It's not
  available for YAML files, such as `compose.yaml`.
- **Beautify** lays the file out again with clear indentation, like
  **Format**.

Nothing is saved until you press **Save**, and <kbd>Ctrl</kbd> <kbd>Z</kbd>
brings the old text back. If the file has a mistake, the editor tells you
what is wrong and leaves your text as it is.

- In a stack, saving `compose.yaml` or `.env` does not deploy. See
  [Stacks](/docs/stacks#edit-the-files).
- If the file changed on the server while you edited it, Docker Manager
  keeps your edits and lets you **Compare**, **Reload from disk**, **Save
  as** another file or **Overwrite**.
- Files larger than 512 KB open as a read-only preview. Raise the size
  with `DOCKER_MANAGER_FILES_MAX_EDIT_KB` (see [Limits](#limits)). Images are
  previewed; other binary files can be downloaded.

## Limits

Each limit has a setting, listed next to it below. Add it under
`environment:` of the `docker-manager` service in your `compose.yaml`, then
run `docker compose up -d` (see
[Configuration](/docs/configuration#change-a-setting)). The settings apply
to all your servers. For example, to edit files up to 2 MB:

```yaml title="compose.yaml"
services:
  docker-manager:
    environment:
      # ...keep the existing lines...
      DOCKER_MANAGER_FILES_MAX_EDIT_KB: 2048
```

| Limit | Default | Setting |
| --- | --- | --- |
| Largest file you can edit in the editor (larger files open read-only) | 512 KB | `DOCKER_MANAGER_FILES_MAX_EDIT_KB` |
| Largest upload, per file (your reverse proxy must allow it too) | 2 GB | `DOCKER_MANAGER_FILES_MAX_UPLOAD_MB` |
| Largest download, or archive you create | 10 GB | `DOCKER_MANAGER_FILES_MAX_DOWNLOAD_MB` |
| Most an extracted archive may write | 10 GB | `DOCKER_MANAGER_FILES_MAX_EXTRACT_MB` |
| Most an archive may grow when extracted | 100 times its size | `DOCKER_MANAGER_FILES_MAX_EXTRACT_RATIO` |
| Most files and folders in one archive | 100,000 | `DOCKER_MANAGER_FILES_MAX_ARCHIVE_ENTRIES` |

**Settings → Overview** shows the limits in effect. Until you
[upgrade](/docs/upgrade) a server's agent, that server keeps the default
limits for downloads and archives, and its uploads stay at 2 GB at most.
Docker Manager's own volumes can't be opened in the file manager.
