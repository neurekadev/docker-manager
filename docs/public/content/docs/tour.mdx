## The menu

The menu on the left has four groups:

| Group | Pages |
| --- | --- |
| (top) | **Dashboard**, **Environments** |
| **Docker** | **Stacks**, **Containers**, **Images**, **Volumes**, **Networks**, **Builds**, **Templates**, **Registries** |
| **Automation** | **Backups**, **Updates**, **Maintenance**, **Jobs**, **Schedules** |
| **Administration** | **Access** (owner only), **Settings** |

You only see the pages you have permission to use. On narrow screens the
menu shrinks to icons, and on phones it opens from the menu button.

## The dashboard

The **Dashboard** shows at a glance:

- how many environments are online and how many containers run,
- CPU and memory use across your servers,
- failed jobs of the last 24 hours,
- a **Needs attention** list: offline servers, failed jobs, containers
  that are not running, stacks with undeployed changes and available
  updates,
- a card for each environment with its CPU and memory use over the last
  30 minutes.

## Choose an environment

With more than one server, the environment switcher at the top of the page
picks what the pages show. **All environments** shows everything at once.

## Search

Press <kbd>Ctrl</kbd> <kbd>K</kbd> (or <kbd>⌘</kbd> <kbd>K</kbd> on a Mac),
or click **Search anything…** at the top. You can jump to any page, stack,
container, image, volume or network, and start common actions such as
**Create stack**.

## Jobs

Deploys, image pulls, updates, backups, cleanups and file operations run as
**jobs**. A job keeps running when you close the browser.

**Jobs** in the menu lists every job, with filters for state, kind,
environment and policy. Open a job to see its steps and result.

- **Cancel job** stops a job that is still running. Steps that already
  finished are not undone.
- **Try again** repeats a failed image pull, deploy, **Pull images only**
  run or update check. For other jobs, the page links to where you can
  start it again.

Finished jobs are kept for 30 days (at most 10,000).

## Notices

The bell at the top shows notices: finished and failed jobs, servers that
went offline and new image updates. Notices live only in the open browser
tab. Docker Manager does not send email or other messages.

## Install it as an app

Docker Manager can be installed as an app from Chrome, Edge and Safari,
on computers and phones. Use your browser's **Install** or **Add to Home
Screen** option. Firefox cannot install it, but works fine in a tab.

## New versions

When Docker Manager was upgraded, a message says **A new version of Docker
Manager is available**. Press **Reload to update**, or **Later** to finish
what you are doing first.
