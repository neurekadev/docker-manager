title: Images, volumes and networks
description: Pull and tag images, manage volumes and their files, and create networks.
---

## Images

**Images** lists the images on your servers, which containers use them,
their size and when they were built. Tick **Unused** to see only images no
container uses.

- **Pull image** downloads an image. Enter a name such as `nginx:1.27`;
  without a tag, `latest` is pulled. The dialog shows which registry login
  it will use (see [Registries and builds](/docs/registries-and-builds)).
- **Tag** gives an image another name. If the tag already exists, it moves
  to this image.
- **Create container** opens the form for a new container, with this
  image filled in (see [Containers](/docs/containers#create-a-container)).
- **Remove** asks you to type the image's name. An image that containers
  still use can't be removed.

Images without a tag are folded at the end of the list. They are older
versions whose tag moved to a newer image. Unused ones are safe to remove,
for example with **Prune images** (see [Cleanup](/docs/cleanup)).

## Volumes

**Volumes** lists your volumes, with filters for driver, stack, unused and
managed volumes.

- **Create volume** makes a new volume. Only volumes with the `local` driver
  support browsing files and backups; others are shown as **Read-only**.
- A volume's **Files** tab lets you browse and edit what is inside (see
  [Files](/docs/files)).
- Its **Backups** tab lists its backups (see [Backups](/docs/backups)).
- Its **Migrate** tab copies it to another server (see
  [Move and rename stacks](/docs/move-and-rename#move-a-volume)).
- **Remove** deletes the volume **and its data**. You must type its name.
  A volume still in use can't be removed.

## Networks

**Networks** lists your Docker networks. Docker's built-in networks
(`bridge`, `host` and `none`) are marked **Predefined**.

- **Create network** makes a new network. You can make it **Internal** (no
  internet access) or **Attachable**.
- A network's page shows its subnets, gateways and attached containers.
- **Remove** deletes a network. Predefined networks, Docker Manager's own
  networks and networks with containers attached can't be removed.

## Act on several at once

On each of these pages, tick rows to remove several items at once. Before
anything runs, you see what will be removed and what is left out, with the
reason. You must type a confirmation, such as `remove 3 images`.
