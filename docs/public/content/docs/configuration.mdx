title: Configuration

---

Docker Manager is set up with settings in your `compose.yaml`. Most people
only need the two in `.env` from the [Quickstart](/docs/quickstart).

## Change a setting

Add the setting under `environment:` of the right service: settings that
start with `DOCKER_MANAGER_` go to `docker-manager`, those that start with
`DOCKER_AGENT_` go to `docker-agent`. For example:

```yaml title="compose.yaml"
services:
  docker-manager:
    environment:
      DOCKER_MANAGER_PUBLIC_URL: ${DOCKER_MANAGER_PUBLIC_URL}
      DOCKER_MANAGER_TRUSTED_PROXIES: ${DOCKER_MANAGER_TRUSTED_PROXIES}
      DOCKER_MANAGER_LOG_LEVEL: debug
```

Then run `docker compose up -d` in the same folder. If a setting is wrong,
the container doesn't start and keeps retrying. Its log says why:
`docker compose logs docker-manager` (or `docker-agent`).

## Manager settings

| Setting | Default | What it does |
| --- | --- | --- |
| `DOCKER_MANAGER_PUBLIC_URL` | (required) | The address you open Docker Manager at. Must start with `https://`. |
| `DOCKER_MANAGER_TRUSTED_PROXIES` | (none) | The IP addresses or networks of your reverse proxy, separated by commas. Only these may tell Docker Manager that a visitor used HTTPS, and who the visitor is. |
| `DOCKER_MANAGER_LOG_LEVEL` | `info` | How much the log says: `debug`, `info`, `warn` or `error`. |
| `DOCKER_MANAGER_SESSION_IDLE_TIMEOUT` | `1h` | Sign out after this long without activity, for example `30m` or `4h`. |
| `DOCKER_MANAGER_SESSION_LIFETIME` | `24h` | Sign out this long after signing in, whatever you do. |
| `DOCKER_MANAGER_FILES_MAX_UPLOAD_MB` | `2048` | The largest file you can upload, in MB (at most 2048). |
| `DOCKER_MANAGER_TEMPLATE_MAX_SIZE_MB` | `32` | The largest template, in MB. |
| `DOCKER_MANAGER_TEMPLATE_REGISTRY_ENABLED` | `true` | Set to `false` to stop sharing your public templates. |
| `DOCKER_MANAGER_MIGRATION_BANDWIDTH_LIMIT` | `0` (no limit) | Limit the speed of moving stacks between servers, for example `50MB`. |
| `DOCKER_MANAGER_BACKUP_LOCAL_ROOTS` | (none) | Folders the manager may write backups to (see [Backups](/docs/backups#allow-a-local-folder)). |
| `DOCKER_MANAGER_METRICS_ENABLED` | `false` | Set to `true` for [Prometheus monitoring](/docs/audit-and-diagnostics#monitoring-with-prometheus). |

## Agent settings

| Setting | Default | What it does |
| --- | --- | --- |
| `DOCKER_AGENT_MANAGER_URL` | (required) | Your Docker Manager address. On the manager's own server, keep `http://docker-manager:8080`. |
| `DOCKER_AGENT_ENVIRONMENT_NAME` | the server's name | The name the server gets when it first connects, if the install command gave it none. |
| `DOCKER_AGENT_STACK_ROOTS` | (none) | Folders with stacks that Docker Manager manages where they are (see [Import existing projects](/docs/import-projects#manage-projects-where-they-are)). |
| `DOCKER_AGENT_BACKUP_LOCAL_ROOTS` | (none) | Folders the agent may write backups to. |
| `DOCKER_AGENT_MANAGER_CA_FILE` | (none) | A certificate file to trust, if your HTTPS certificate comes from your own certificate authority (see below). |
| `DOCKER_AGENT_LOG_LEVEL` | `info` | How much the log says: `debug`, `info`, `warn` or `error`. |

## Docker's data folder

The agent must see Docker's volume folder at the same path as the server.
If your Docker keeps its data somewhere other than `/var/lib/docker`, find
the folder with:

```bash
docker info -f '{{.DockerRootDir}}'
```

Then replace `/var/lib/docker` with it in both agent lines. For example,
with `/data/docker`:

```yaml
      - /data/docker/volumes:/data/docker/volumes
      - stacks:/data/docker/volumes/docker-manager_stacks/_data
```

## Your own certificate authority

If your HTTPS certificate is not trusted by default (it comes from your own
certificate authority), agents on other servers must trust it. Put the
authority's certificate next to the agent's `compose.yaml` as `ca.pem`, and
add:

```yaml title="compose.yaml"
services:
  docker-agent:
    environment:
      # ...keep the existing lines...
      DOCKER_AGENT_MANAGER_CA_FILE: /etc/docker-manager/ca.pem
    volumes:
      # ...keep the existing lines...
      - ./ca.pem:/etc/docker-manager/ca.pem:ro
```

## SELinux

On servers with SELinux turned on, add this to the agent:

```yaml
    security_opt:
      - label=disable
```

Don't add `:z` or `:Z` to the Docker socket or `/var/lib/docker/volumes`.

## Your data

Everything Docker Manager stores is in Docker volumes:

- `docker-manager_data`: the manager's database and its key file. Never
  delete it, and back it up (see [Backups](/docs/backups)).
- `docker-manager_agent`: the agent's identity.
- `docker-manager_stacks`: your stacks' folders.
