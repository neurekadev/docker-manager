---
title: Add more servers
description: Connect another Docker server to Docker Manager.
---

Every Docker server you want to manage needs its own agent. The agent
connects to your Docker Manager address over HTTPS. The server needs no open
ports.

The server needs Linux (amd64) and Docker Engine 25.0 or newer.

## 1. Create an install command

1. In Docker Manager, open **Environments** and press **Add environment**.
2. Give it a name if you like, and press **Create install command**.

The page shows the command in three tabs. The command works once and
expires after one hour. Under **More options** you can pick a longer time,
up to 24 hours.

## 2. Start the agent

Log in to the image registry on the new server first, as in
[step 1 of the Quickstart](/docs/quickstart#1-log-in-to-the-image-registry).

Then pick one of the two ways below.

### With a single command

Open the **On another Docker host** tab, copy the command and run it on the
new server. It starts the agent and connects it.

### With Compose

Use this way if you like to keep your setup in files.

1. Make a folder, for example `/opt/docker-manager`, and create this
   `compose.yaml` in it:

   ```yaml title="compose.yaml"
   name: docker-manager

   services:
     docker-agent:
       image: code.neureka.dev/docker-manager/docker-agent:edge
       restart: unless-stopped
       environment:
         DOCKER_AGENT_MANAGER_URL: ${DOCKER_AGENT_MANAGER_URL}
         DOCKER_AGENT_ENROLLMENT_TOKEN: ${DOCKER_AGENT_ENROLLMENT_TOKEN:-}
         DOCKER_AGENT_ENVIRONMENT_NAME: ${DOCKER_AGENT_ENVIRONMENT_NAME:-}
       volumes:
         - /var/run/docker.sock:/var/run/docker.sock
         - /var/lib/docker/volumes:/var/lib/docker/volumes
         - stacks:/var/lib/docker/volumes/docker-manager_stacks/_data
         - agent:/var/lib/docker-agent
       labels:
         dev.neureka.docker-manager.role: agent

   volumes:
     agent:
     stacks:
   ```

2. Open the **On another Docker host, with Compose** tab. Copy only its
   lines that start with `DOCKER_AGENT_` into a file named `.env` next to
   `compose.yaml`. It looks like this:

   ```bash title=".env"
   DOCKER_AGENT_MANAGER_URL=https://docker.example.com
   DOCKER_AGENT_ENROLLMENT_TOKEN=dye_...
   ```

3. Start the agent:

   ```bash
   docker compose up -d
   ```

Once the server shows as connected, you can remove the
`DOCKER_AGENT_ENROLLMENT_TOKEN` line from `.env`. The token works only once
anyway.

## 3. Wait for it to connect

The Docker Manager page shows **Connected** within a few seconds. The new
environment appears in **Environments** and in the environment switcher at
the top of the page.

If it does not connect, see [Troubleshooting](/docs/troubleshooting).

## Good to know

- One Docker server can have only one agent. To connect a server again
  whose agent you removed or whose environment you archived, use
  **Re-attach** instead (see [Environments](/docs/environments#re-attach-an-environment)).
- A cloned virtual machine looks like the server it was cloned from. For
  such a server, tick **This host is a clone of a connected host** under
  **More options** before you create the command.
- Pending commands are listed under **Waiting for an agent** on the
  **Environments** page. Press **Revoke** to cancel one.
